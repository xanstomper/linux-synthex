# Synthex Touch

**Tablet & handheld. Finger-friendly. Bold.**

## Layout
- Top bar (48px, back + launcher + clock + battery)
- Floating bottom dock (64px, large touch targets)
- Grid menu for finger navigation
- Bold rounded corners everywhere

## Visual
- Frost light theme with blue accents (#5B9BD5)
- Slow smooth animations (1.2x)
- OpenGL compositor
- Large touch targets (64px minimum)

## Performance
- **Balanced**
- Perfect for: Tablets, handhelds (ROG Ally, Legion Go, Steam Deck)

## Features
- On-screen keyboard enabled
- Handheld mode integration
- Touch-friendly grid launcher
- Auto-rotate support

## Keybindings
- Swipe from left → Workspace overview
- Swipe from right → Quick settings
- Long press → Context menu
- Meta+O → Toggle OSK

## Apply
```bash
synthex-desktop apply touch
```
