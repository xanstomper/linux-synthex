# Synthex Lite

**Lightweight. Fast. Old hardware friendly.**

## Layout
- Bottom panel (32px, minimal)
- SimpleMenu (no search, no graphics)
- Basic system tray
- Solid color desktop (no wallpaper)

## Visual
- Dark graphite with gray accents (#8899AA)
- No animations (disabled entirely)
- XRender compositor (most compatible)
- No blur, no transparency, no effects

## Performance
- **Lightweight** — minimum RAM/CPU usage
- Perfect for: Old hardware (10+ years), VMs, low-spec systems

## Resource Usage
- **RAM:** ~300MB idle
- **CPU:** Near-zero idle
- **GPU:** No 3D required
- **Disk:** ~2GB for full desktop

## Keybindings
- Meta → App launcher
- Alt+F2 → Run command
- Alt+Tab → Window switcher

## Apply
```bash
synthex-desktop apply lite
```
