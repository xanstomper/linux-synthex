# Synthex Studio

**Content creator. Color-accurate. Media-centric.**

## Layout
- Top bar (36px, minimal)
- Right sidebar (240px, floating, color palette + system monitor + media)
- Media controller always visible

## Visual
- Latte warm theme with rose accents (#D65D7A)
- Smooth animations (1.0x)
- OpenGL compositor
- Color-accurate display profile

## Performance
- **Balanced**
- Perfect for: Designers, video editors, streamers, photographers

## Features
- Color palette sidebar widget
- System monitor always visible
- Media playback controls
- Color-accurate display calibration
- OBS Studio integration

## Keybindings
- Meta+S → Toggle sidebar
- Meta+P → Color picker
- Meta+R → Screen recording
- PrintScreen → Screenshot tool

## Apply
```bash
synthex-desktop apply studio
```
