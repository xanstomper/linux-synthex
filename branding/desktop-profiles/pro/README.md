# Synthex Pro

**Developer cockpit. Split-panel. Terminal-first.**

## Layout
- Left app dock (48px, icon-only launcher)
- Bottom status bar (32px, workspace pager + tasks + clock)
- Terminal launcher in dock
- Folder desktop with dev tools

## Visual
- Dark graphite with blue accents (#5B9BD5)
- Fast snappy animations (0.7x)
- OpenGL compositor
- Blur on panels

## Performance
- **Balanced**
- Perfect for: Developers, creators, heavy multitaskers

## Features
- Built-in terminal launcher button
- Git-aware file manager (Dolphin fork)
- Multi-workspace by project
- Monitor profile switching for coding

## Keybindings
- Meta+T → Terminal
- Meta+E → File manager
- Meta+Shift+D → Developer tools
- Ctrl+Alt+→ → Next workspace

## Apply
```bash
synthex-desktop apply pro
```
