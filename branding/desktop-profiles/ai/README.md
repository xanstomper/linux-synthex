# Synthex AI

**AI-first desktop. Assistant everywhere. Smart workspace.**

## Layout
- Top bar (32px, with AI search integrated)
- Left sidebar (320px, AI chat + context + agents + models)
- Floating dock for apps
- AI search replaces traditional launcher

## Visual
- Deep black with mint accents (#9BBD5C)
- Smooth animations
- OpenGL compositor
- Blur on all panels

## Performance
- **Balanced** (AI daemon running in background)
- Perfect for: AI users, researchers, power users

## Features
- **AI Chat** — Talk to local LLM
- **AI Context** — Current file/project context
- **AI Agents** — Automated task agents
- **AI Models** — Browse and switch models
- AI search across files, apps, settings, web
- Voice input (whisper)
- Clipboard AI actions

## Keybindings
- Meta+Space → AI search
- Meta+Shift+A → Toggle AI sidebar
- Meta+Shift+C → New AI chat
- Meta+Shift+V → Voice input
- Meta+Shift+Space → Quick AI ask

## Apply
```bash
synthex-desktop apply ai
```
