# Synthex Classic

**Windows-like. Familiar. Easy onboarding.**

## Layout
- Bottom panel (40px, Windows-style taskbar)
- Start menu (Windows-style kickoff)
- Quick launch + system tray
- Folder desktop

## Visual
- Mint green theme with warm green accents (#86C166)
- Normal animations (1.0x)
- OpenGL compositor
- No blur (maximum compatibility)

## Performance
- **Balanced**
- Perfect for: Windows migrants, beginners, office users

## Features
- Windows-like start menu
- System tray with all icons
- Desktop shortcuts
- Familiar Alt+Tab
- File explorer with ribbon UI

## Keybindings
- Meta → Start menu
- Meta+E → File explorer
- Alt+Tab → Window switcher
- Ctrl+Shift+Esc → Task manager

## Apply
```bash
synthex-desktop apply classic
```
