# Synthex Gaming

**Console-like. Big Picture. Zero distractions.**

## Layout
- Floating bottom dock (Steam + launcher + tasks)
- Big Picture Mode ready
- Auto-hides in games
- Amber accents on deep black OLED background

## Visual
- Deep black (#000000) with amber accents (#FFB300)
- Smooth fluid animations (1.5x)
- OpenGL compositor with full performance
- HDR/VRR ready

## Performance
- **Balanced** — GameMode auto-enabled
- Perfect for: Gamers, Steam Deck-like experience

## Features
- Steam Big Picture launches automatically
- Gamescope session ready
- MangoHUD pre-configured
- Controller-friendly UI

## Keybindings
- Meta+A → Quick launch Steam
- Meta+G → Toggle GameMode
- Controller Guide → Gaming menu

## Apply
```bash
synthex-desktop apply gaming
```
