# Synthex Focus

**Minimal. Keyboard-centric. Zero distractions.**

## Layout
- 28px ultra-thin top bar (launcher + clock + tray)
- No dock — everything is keyboard-driven
- SimpleMenu (no search, just clean categories)
- Folder desktop (no widgets)

## Visual
- Dark graphite (#0B0F1A) with mint accents (#9BBD5C)
- Fast animations (0.5x speed)
- XRender compositor (lightweight)
- Everything auto-hides

## Performance
- **Lightweight** — minimal RAM, no blur, no effects
- Perfect for: Power users, minimalists, keyboard-driven workflows

## Keybindings
- Meta → Application launcher
- Meta+Space → Search (like Arc Browser)
- Meta+1-9 → Switch workspaces
- Alt+Space → Quick commands

## Apply
```bash
synthex-desktop apply focus
```
