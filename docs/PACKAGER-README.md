## Quick build commands

```bash
# Validate kickstarts only (no build dependencies needed)
make ks-validate

# Build Rust workspace (requires cargo)
make rust

# Build single ISO (requires lorax + livemedia-creator)
make iso EDITION=plasma VERSION=2026.10

# Build all 5 editions in parallel (~6h, ~100 GB disk)
make iso-all VERSION=2026.10

# Full release bundle
make release VERSION=2026.10
```

## Known packaging gotchas

1. **GRUB font** — `font-regular.pf2` is pre-built (shipped binary).
   If you need to rebuild it: `grub2-mkfont -s 14 -o font-regular.pf2 NotoSans-Regular.ttf`

2. **Plymouth theme** — must be in `/usr/share/plymouth/themes/synthex/` and
   registered with `plymouth-set-default-theme synthex` in post-install.

3. **SDDM** — place theme in `/usr/share/sddm/themes/synthex-sddm-theme/` then
   set `Current=synthex-sddm-theme` in `/etc/sddm.conf.d/synthex.conf`.

4. **Calamares branding** — `branding.desc` path must match the `branding` key
   in `settings.conf` exactly: `synthex`.

5. **Rust binaries** — built with `cargo build --release`, NOT `--debug`.
   Strip symbols for production: `strip target/release/synthex-*`

## Building all RPMs + a local repo (pre-ISO testing)

All packaging runs inside a **Fedora container** (this repo is developed on
other distros; `lorax`/`rpmbuild` are Fedora-native):

```bash
# 1. enter the build container
make dev-container          # or: podman run -it --rm -v $PWD:/src fedora:rawhide bash

# 2. generate every Source0 tarball from the repo (no network needed)
cd /src && ./build/scripts/make-srctars.sh

# 3. build all packages + assemble build/repo/ with createrepo_c
./build/scripts/local-repo.sh
```

**Workspace crates.** Rust crates that are members of the root Cargo
workspace (`synthguard`, `synthex-hwdaemon`, …) use `workspace = true`
dependencies, so their Source0 is a *full-workspace* tarball and the spec's
plain `cargo build --release` resolves every member correctly.

**Orphan specs.** `synthex-firmware`, `synthex-vpn` and
`synthex-neurofeedback` reference sources not yet in-tree; `make-srctars.sh`
flags and skips them (they are not in any kickstart/comps group).

**Local kickstart.** To build a test ISO against the local repo:

```bash
sed "s|https://packages.getsynthex.org/stable/x86_64/|file://$(pwd)/build/repo|"     build/kickstart/synthex-plasma.ks > build/kickstart/synthex-plasma-local.ks
```

`gpgcheck=0` in the local repo is **dev-only** — a published repo must be
GPG-signed (see `docs/security/privacy-and-security.md` for the trust model).

## User & system accounts

| Account | Purpose | Created by |
|---------|---------|------------|
| `synthex-brain` | Brain OS daemons (brain, hermes, neural-ipc, workspace-ai) | `synthex-brain.sysusers` → `/usr/lib/sysusers.d/synthex-brain.conf` |
| `synthex-agent` | Agent sandbox worker | `synthex-agent.sysusers` |
| `synthex-aether` | AETHER core | `synthex-aether.sysusers` |
| `synthex-sentinel` | AETHER sentinel | `synthex-sentinel.sysusers` |

User-session services (e.g. `synthex-memory-palace.service`) install to
`~/.config/systemd/user/` and never hardcode a username.

## New-user skeleton (`/etc/skel`)

| Edition | What new users get |
|---------|--------------------|
| Hyprland | hypr/waybar/wofi/mako/kitty configs, fish + starship + fastfetch |
| Plasma   | plasmarc, kdedefaults (look-and-feel, SynthexFocus colors) |
| GNOME    | gschema overrides (theme, icons, wallpaper, favorite-apps) |
| All      | XDG user-dirs defaults, fontconfig (Inter + JetBrains Mono) |

Regression guards: `tests/run-tests.py` sections 65–70 verify spec path
integrity, component coverage, sysusers and skel wiring on every run.
